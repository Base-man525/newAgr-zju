## 信息维护建议

| 项目 | 建议 |
| --- | --- |
| 姓名 | 使用成员本人确认的展示名称 |
| 照片 | 使用获得授权的图片，并填写准确的替代文本 |
| 介绍 | 保持简短，不展示身份证号、住址等敏感信息 |
| 联系方式 | 默认不公开；确需公开时先取得明确同意 |

新增成员时，可以复制一张成员卡片并替换其中的占位文字。若成员较多，可继续增加卡片，页面会自动换行排列。
