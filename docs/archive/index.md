# 资料归档

这里用于整理活动照片、文档、表格和往期材料。归档时保留来源、日期和授权状态，方便以后查找。

## 归档分类

| 分类 | 内容 | 保存位置 |
| --- | --- | --- |
| 活动材料 | 活动方案、记录和成果 | `docs/assets/attachments/` |
| 图片资料 | 经授权发布的照片 | `docs/assets/images/` |
| 公告留档 | 已结束的重要公告 | 在公告页面中归档 |
| 班级文档 | 章程、名单和公开材料 | `docs/assets/attachments/` |

## 文件命名建议

使用“日期-主题-版本”的英文小写名称，便于排序和兼容链接，例如：

```text
2026-11-20-class-meeting-minutes.pdf
2026-12-01-winter-activity-cover.webp
```

## 发布前检查

!!! warning "文件安全"

    上传前检查文件是否包含身份证号、家庭住址、电话、成绩单或其他敏感信息。大型照片建议压缩后再上传，避免网站仓库体积持续增大。
