# 关于本站

本站是面向班级成员、老师和访客的信息展示与记录空间。当前内容为结构示例，不代表任何真实班级经历。

## 网站用途

- 介绍班级概况和共同目标。
- 发布班级公告和活动安排。
- 保存经授权的活动记录和公开资料。
- 为班级成员提供稳定的常用入口。

## 技术方案

| 部分 | 方案 |
| --- | --- |
| 内容 | Markdown |
| 构建 | MkDocs |
| 主题 | Material for MkDocs |
| 中文排版 | `mkdocs-heti-plugin` |
| 部署 | GitHub Actions + GitHub Pages |

`mkdocs-heti-plugin` 会在构建阶段优化中文正文的中西文间距和连续标点，不会改写 Markdown 的原始数据。

## 内容责任

网站维护者应定期检查公开内容，及时删除过期公告和不再适合公开的信息。涉及成员个人资料、照片和联系方式的内容，必须先取得本人同意。
