## 单次活动怎么记录

建议每项活动包含以下信息：

1. 活动名称、时间和地点。
2. 活动目的与参与范围。
3. 过程摘要和关键成果。
4. 获得授权的照片或附件。
5. 后续安排或经验总结。

## 示例活动模板

```markdown
## 活动名称

- 时间：[日期]
- 地点：[地点]
- 参与人员：[参与范围]

### 活动过程

[活动过程摘要]

### 活动成果

[成果、感受或后续安排]
```
